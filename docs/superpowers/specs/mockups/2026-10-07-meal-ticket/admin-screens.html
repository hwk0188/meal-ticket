관리자 화면 설계 원칙
  • 발급이 2탭. 발급 탭을 열면 다음 식사가 이미 선택되어 있고, 이름 검색 → 장수 확인 → 발급. 여러 명을 연달아 처리하는 입금 확인 작업에 맞춤.
  • 식사 상세 = 당일 현황판. 배식 중 권사님이 보는 화면. 발급·사용·남음이 실시간으로 바뀌고, 명단에서 바로 대신 사용 처리.
  • 위험한 동작은 한 단계 더. 발급 취소·사용 무효·사람 합치기는 ⋯ 메뉴 → 확인 창. 실수로 누르기 어렵게.
  • 관리자도 교인. "내 식권" 탭으로 자기 식권 화면에 바로 감. 권사님도 식사하시니까.
  • 개인정보는 여기까지만. 전화번호 전체는 사람 탭에서만, 교인 화면에서는 가운데가 가려짐.
